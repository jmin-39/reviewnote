## 📊 3장 빅쿼리 실습 데이터

이 폴더는 『데이터 분석 오답 노트』 3장에서 사용하는
BigQuery 실습용 데이터셋을 제공합니다.

실습 데이터를 활용하여 SQL 기반 데이터 분석과
데이터 추출, 집계, JOIN, 전처리 과정을 직접 따라해볼 수 있습니다.

## 📂 파일 구성

| 파일명 | 설명 |
|---|---|
| customers.csv | 고객 정보 데이터 |
| orders.csv | 주문 데이터 |
| order_items.csv | 주문 상세 데이터 |
| products.csv | 상품 정보 데이터 |
| reviews.csv | 리뷰 데이터 |
