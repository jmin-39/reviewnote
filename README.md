### 1️⃣ ZIP 파일로 다운로드 (추천)

1. 상단의 초록색 **[Code]** 버튼을 클릭합니다.
2. **[Download ZIP]** 을 선택합니다.
3. 내 컴퓨터에서 압축을 해제한 후 실습에 활용합니다.
