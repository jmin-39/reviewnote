## 📂 데이터 다운로드 방법

실습 데이터를 내 컴퓨터로 가져오는 방법은 두 가지입니다.

### 1️⃣ ZIP 파일로 다운로드 (추천)
GitHub 계정이 없어도 누구나 간편하게 받을 수 있습니다.
1. 상단의 초록색 **[Code]** 버튼을 클릭합니다.
2. **[Download ZIP]**을 선택합니다.
3. 내 컴퓨터에서 압축을 해제한 후 실습에 활용합니다.

### 2️⃣ Git Clone (숙련자용)
터미널 또는 CMD에서 아래 명령어를 입력하세요.
```bash
git clone [https://github.com/username/repository-name.git](https://github.com/username/repository-name.git)


## 💡 실습 전 확인 사항
- 데이터 형식: 모든 실습 데이터는 CSV 형식으로 제공됩니다.

- 인코딩 안내: 한글 깨짐 방지를 위해 UTF-8 형식을 권장합니다. (Excel에서 열 때 주의하세요!)

- 준비 도구: 각 장의 환경설정 안내에 따라 등을 미리 설치해 주세요.
